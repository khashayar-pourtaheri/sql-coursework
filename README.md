# SQL coursework

SQL and SQL++ queries I wrote for CSE 344 (Introduction to Data Management) at the
University of Washington, Autumn 2022.

- `create-tables.sql`: schema and data import for the flights database (SQLite)
- `hw2-q1.sql` to `hw2-q8.sql`: joins, filters and aggregation on the flights data
- `HW3-q1.sql` to `HW3-q7.sql`: subqueries, grouping and nested queries
- `q1.sqlp` to `q9.sqlp`: SQL++ queries on semi-structured (JSON) geography data
- `Driving.sql`: turning an E/R diagram into tables with keys and references
- `frumble.sql`: finding functional dependencies with SQL
- `hw3-writeup.txt`: short notes on using a cloud database
